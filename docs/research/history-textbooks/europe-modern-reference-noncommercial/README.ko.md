# 현대 유럽·세계사 보완용 원문 검증 자료

검증일: 2026-11-13. 국가별 단일 통사가 아니라 유럽·세계사 보완 참고자료다. 전체 번역은 시작하지 않았다. 독일 작업은 보류 상태를 유지한다.

## 범위: 홈페이지 안내와 실제 본문 구분

저자 홈페이지는 제3권을 1800–2017로 소개한다. 하지만 실제 V3.0 제15장은 약 2020년까지를 다룬다고 설명하면서 2021년 미국 의사당 사건·아프가니스탄, 2022년 러시아의 우크라이나 침공, 2023년 이스라엘·가자 및 기후 관련 정보를 부분적으로 포함한다. 따라서 ‘1800–2017 안내, 약 2020년 중심의 최근사와 2023년까지 일부 추가’로 기록한다. 모든 국가의 역사를 2023년 또는 2024년까지 완결한 교재라는 뜻이 아니다.

나폴레옹, 산업혁명, 정치사상, 19세기 정치, 문화·과학, 제국주의, 제1차 세계대전, 20세기 초, 파시즘, 제2차 세계대전, 홀로코스트, 소련·냉전, 전후 갈등, 전후 사회, 최근사라는 15개 주제 장이다.

## 사용 판단

비상업 연구용 원문은 확보했다. 다만 포클랜드의 대양과 이라크 침공 연도라는 명백한 오류가 최신 판본에도 남아 있어, 검증 완료된 정답 데이터나 무교정 전문 번역 원본으로 즉시 채택하지 않는다. NVCC 개작판과도 같지 않다. 세 표본의 차이와 공식 정정 근거는 VERIFICATION.partial-ko.md를 따른다.

- 영국·프랑스: 제국주의, 두 세계대전, 탈식민화, 전후 복지·정치·사회 변화, 유럽통합의 공통 배경을 보충하기에 상대적으로 유용하다. 영국의 대처·브렉시트, 프랑스의 알제리·드골·1968년 등이 실제 본문에 있다. 국가별 현대 통사를 대체하지 않는다.
- 이탈리아: 통일 이후의 유럽 맥락, 파시즘·무솔리니·세계대전, 전후 유럽통합의 비교 자료로 유용하다. 전후 공화국과 최근 정치 전체가 체계적으로 이어지는 이탈리아 단독 통사는 아니다.
- 스페인: 19세기·내전·프랑코·유럽통합 맥락을 보충할 수 있으나 민주화 이후 현대사의 단독 완결 자료로 부족하다. 기존 교육부 교재를 대체하지 않는다.
- 미국: 유럽과의 관계·세계대전·냉전 비교에 한정된 보완 용도다. 기존 American Yawp를 대체할 필요는 없다.
- 일본·중국·한국: 제국주의·아시아 전쟁·냉전의 주변 문맥으로 등장하지만 각국 현대 통사의 공백을 채우는 주원문으로 부적합하다.
- 독일: 내용이 포함되어 있어도 별도 수집·번역·채택 작업은 진행하지 않았다.

## 권리와 배포

- 본문 재사용은 https://creativecommons.org/licenses/by-nc-sa/4.0/ 및 원문 표시에 따른다. 저자·제목·출처·라이선스를 밝히고 변경·번역·정정을 표시한다. 비상업 용도로 제한하고, 번역 등 개작물을 공개할 때 같은 라이선스 조건을 유지한다. 권리자가 지닌 권한 범위만 허락되며 별도 제3자 권리는 그대로다.
- 본문과 공식 저자 안내, CC 4.0 조건에서 별도 생성형 AI 이용 금지 조항은 찾지 못했다. 이는 확인한 문서 범위의 결과이며 웹사이트 전체·연결된 모든 자료·AI 학습 또는 상용 서비스 이용에 대한 포괄 허가나 법률 검토 결과가 아니다. AI로 만든 번역·각색이라고 비상업·동일조건 의무가 없어지지 않는다.
- DOCX에는 저자가 Fair Use라고 표시한 제3자 이미지가 포함되어 있다. 원본 연구 보존과 외부 재배포를 구별한다. DOCX 전체를 권리 검토 없이 서비스 자산이나 공개 재배포 묶음에 넣지 않는다.
- 이미지별로 Public Domain, 별도 CC, Fair Use, 출처만 있는 경우가 섞여 있다. 특히 Nick Ut/AP의 Napalm Attack, Warhol의 Campbell's Soup, Sgt. Pepper's 표지는 자유 재배포 허가로 취급하지 않는다.
- 이미지 출처 83개 항목을 image-citation-inventory.json에 전사했지만 모든 이미지의 권리를 개별 확정한 것은 아니다. source-links.json은 DOCX의 실제 링크 85개를 보존한다. 외부 사이트 변경과 단절 링크도 있을 수 있다. 공개 영역 표시 역시 모든 국가에서의 권리 보증이 아니다.

## 파일

- source-manifest.json: 공식 원문 URL·판본·범위·응답 상태·파일 크기·해시·구조 검증.
- source-author-page.html: 공식 저자·판본 안내 사본.
- license-cc-by-nc-sa-4.0.txt: Creative Commons의 공식 법률문 사본.
- source-links.json: DOCX에 실제 포함된 하이퍼링크와 문단 번호.
- image-citation-inventory.json: 장별 원문 이미지 권리·출처 표시 전사. 독립 권리 확인 완료 목록이 아니다.
