## 권리·출처 보완

원서의 PDF 3쪽은 역사 개념 집필자를 제1·2·4장 Lorena Álvarez Delgado, 제3·5장 Patricia Lucas Alonso, 제6·7·8장 Joaquín Pascual López로 명시한다. 개념 편집·검토는 Lara Torrego Otero와 Joaquín Pascual López이다. PDF 5–6쪽은 일반 언어 어휘와 역사 개념·전문 어휘를 구별하고, 175쪽의 RAE·WordReference 목록은 Vocabulario 아래에 배치되어 있다.

이 근거와 페이지별 인용·출처 표시, 문구 대조를 토대로 이번 설명을 ‘집필자 귀속 개념 설명’으로 편집상 분류했다. **‘표절 아님’, ‘모두 완전한 자작임’, ‘재배포 권리 검증 완료’라는 확정 판단은 아니다.** 외부 인용 표시가 없거나 문구검색에서 선행 자료가 나오지 않은 것만으로 독창성을 증명할 수 없다. 선행 사전·백과와 긴 문구가 겹치거나 파생 관계가 미해결인 항목은 아래와 같이 별도 보류했다. 짧은 공통 사실이나 일반적 표현이 같다는 것만으로 권리 침해를 단정하지 않는다.

책의 Creative Commons Atribución-NoComercial-CompartirIgual 표기는 버전이 없다. 임의로 3.0·4.0이라고 정하지 않는다. 비상업·출처표시·동일조건 연구 초안으로 분리하며 앱·상용 DB에 통합하지 않는다. Wikipedia의 현재 CC 표시를 교재의 모든 파생·귀속 조건이 충족되었다는 증거로 삼지 않았다. 사전 정의·외부 인용·가사·이미지는 같은 권리라고 가정하지 않았다.

## 개념 안의 정확한 미완료 항목

- 제4장 PDF 59쪽 10번 **fuero**: 외부 푸에로 설명과 긴 문구의 파생 관계 미해결. 정의 전체 미번역.

- 제5장 PDF 84쪽 19번 **Movimiento regionalista**, 26번 **Sagasta**, 27번 **Santa Alianza**: 정의 전체 미번역.

## QA와 원문 보존

- 새 개념 원문 17쪽 전체, 안내 2쪽은 렌더 이미지와 대조했다. 통합 부록은 15쪽 전 항목을 PDF 텍스트 좌표로 대조하고 152·154·166쪽을 시각 표본 확인했다. 모든 부록 쪽을 시각 검토했다고 주장하지 않는다.
- 원문 표제어 대응에서는 Comunismo의 관사 차이 1건, Guerra de Irak와 protestante의 대소문자 차이 2건, Leyes의 추출 공백 차이 1건을 구분했다. 정의 내용의 차이는 아니며 상세 대응은 QA에 기록했다.
- 장별 표제어 순서·개수 203개가 모두 일치한다. 통합 부록 203개 정의도 장별 원문과 공백·대소문자를 정규화한 뒤 203개 모두 일치했다. 외부 자료를 새 정의로 채워 넣지 않았다.
- 정의 전문 190개의 원문 아라비아 숫자 값이 한국어 정의·표제어에 존재하는지 검사한 결과 누락 0건. 이 검사는 숫자의 중복 횟수·문맥·의미까지 자동 보증하지 않는다. 로마 숫자·문자로 쓰인 수·월·범위·단위를 장별 메모에서 따로 대조했다.
- 원문의 의심스러운 날짜·인과 설명은 조용히 수정하지 않았다. 트리엔트공의회 끝 연도 1552, 예수회 추방 1787, 가문 협약 1733/1761/1789, 산후르호의 1936년 2월, 무솔리니의 1923년, ETA의 1958년 등은 별도 감수 대상으로 남겼다. 이 목록은 해당 내용의 사실 검증 결과가 아니다.
- 기존 본문과 개념 사이의 차이도 남겼다. 예를 들어 개발계획은 본문 PDF 108쪽에서 1962–1975, 개념 PDF 119쪽에서 1964–1975이다. 한쪽을 다른 쪽에 맞춰 덮어쓰지 않았다.
- 본문과 연결되는 민족봉기·자치헌장·국가가톨릭주의·뮌헨의 음모·민주수렴플랫폼 등의 번역어를 맞췄다. 초기 새 초안의 표현을 다듬은 판본도 `tmp/concepts-draft-revisions/`에 보존했다. 기존 본문 8개·통합본·연표 8개·활동 8개·권리목록의 manifest 등록 26개 파일은 해시가 모두 동일하다.
- 원본 PDF SHA-256 `52f69a10d2ad5c679b922a39b185065438b1211554abef0fa3c134010ab251ab`, 14,018,454바이트·278쪽을 재확인했다. 원본 PDF와 모든 기존 초안은 수정하지 않았다. 커밋·푸시·앱·DB 변경 없음.

## 시대 범위의 주의점

**주요 서술 본문의 사건 종점은 2011년이지만, 책 전체 구성의 종점이 2011년이라는 뜻은 아니다.** PDF 137–138쪽 개념의 Ciudadanos·Podemos는 2015·2016년 선거 정보를 포함한다. 출간일은 2016년 11월 28일이다. ‘2011년 이래 총리’ 등은 당시 시점 그대로 번역했으며 현재 직위·현재 정치 상황의 설명으로 쓰지 않는다.
