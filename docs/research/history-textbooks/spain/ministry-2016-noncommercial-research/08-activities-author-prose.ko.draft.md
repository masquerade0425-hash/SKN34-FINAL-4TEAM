## PDF 128쪽

### 2.1.

세 명씩 모둠을 이루어 앞에 나온 장소·인물·요소들로 짧은 이야기를 만들어 보세요. 창의력을 발휘하세요.

작은 도움말: 이야기를 쓸 때는 과거 시제를 사용해야 한다는 점을 기억하세요.

**불완료과거(Pretérito Imperfecto)**

- -AR → -ABA
- -ER, -IR → ÍA
- SER → ERA
- IR → IBA

**단순과거(Pretérito Indefinido)**

| -AR | -ER/-IR |
| --- | --- |
| -é | -í |
| -aste | -iste |
| -ó | -ió |
| -amos | -imos |
| -asteis | -isteis |
| -aron | -ieron |

[스페인어 문법 연습을 유지하기 위해 원문의 활용형은 번역하지 않고 그대로 보존했다. 새로운 인칭 설명이나 정답은 추가하지 않았다.]
