# 남은 범위: 현대 통사·세계관 검수·서비스 적용

## 현재 무엇이 끝났는가

[읽기 안내](READING-INDEX.ko.md)에 연결된 8개국 자료의 지정 범위 한국어 초안과 창작 후보38개를 저장했다. 이것은 8개국의 고대부터 현재까지 최신 교과서를 모두 확보하고 전문가 감수까지 마쳤다는 뜻이 아니다. 고전 번역은 원저의 기록이며 현대의 정확한 역사 설명으로 바로 제공하면 안 된다. 독일은 계속 보류한다.

## 현대 통사 확보에서 남은 일

- 미국: American Yawp28장 스냅샷이 현대까지 이어지지만 최신성과 문장별 정확성은 별도 검증이 필요하다. CC BY-SA4.0 본문과 별도 조건 이미지·인용을 분리하고 출처·변경 고지를 유지해야 한다. 4개 장의 표본 검수는28장 전수 검수의 대체가 아니다.
- 프랑스: 현재 번역의 주된 종점1871년 이후 공백. 현대 교육자료 후보는 국가 전체 시대를 포괄하는지와 이용조건의 일관성이 아직 확인되지 않았다.
- 영국: 고전1902년 이후 공백. NLS정부연감은 현대의 당시 상황을 보완할 수 있는 후보지만 연속 통사 교과서가 아니며 제3자 자료와 실제 이용조건 확인 전 일괄 채택하지 않는다.
- 이탈리아: 고전의 주된 범위476~1870년 및1874년 평가. 고대 전체와 이후 현대사 보완 필요. Storia C3 후보는 전체 안정적 접근·판본·자료별 조건을 확정하지 못했다.
- 스페인: 2016년 교재 본문은2011년, 일부 개념은2015~2016년까지다. 허용 범위의 자작자료는 옮겼지만 외부 인용·사전 정의 등은 보류했다. 비영리 조건과 동일조건변경허락을 상업 서비스에 적합하다고 가정하지 않는다. 별도 후보 The Nation in Its Labyrinth는 ND/SA 조건 모순을 해결하기 전 개작하지 않는다.
- 일본: 19세기 고전 이후 공백. Wikibooks 후보의 확인된 인명·연대 오류 때문에 통째 채택하지 않는다. LOC 접근403을 다른 미러로 우회하지 않는다. Country Studies 미러의 나가사키 날짜 오류도 있어 근거 없는 현대사 대체본으로 쓰지 않는다.
- 한국: 고전1904년 이후 공백. AKS2019 책은 복제에 서면 허가가 요구되므로 전문 저장·번역 후보로 채택하지 않는다. 단편 주제 글이나 권리 미확정 데이터는 현대 통사 완성으로 계산하지 않는다.
- 중국: 고전1898년 이후 공백. MIT 강좌·Columbia 자료집은 교수 계획과 주제별 원자료를 찾는 참고 경로이지 단일 현대 통사나 수록 도서의 무료 복제 허가가 아니다. LOC403 접근은 중단 상태다.

Brooks2024 현대 유럽 원문은 별도 비영리 참고 폴더에 확보했으나 사실 오류와 Fair Use 이미지가 확인됐다. 전체를 검증된 국가별 최신 통사로 쓰거나 이미지까지 자유롭게 재배포할 수 있다고 판단하지 않는다. 후보별 세부 근거와 기존 확인 상태는 [현대 자료 기록](MODERN-CANDIDATES.partial-ko.md)을 따른다. 이 문서는 새 권리 판단이나 새 다운로드 승인 기록이 아니다.

다음 자료를 채택하려면 출판 주체·저자·판본·실제 전체 접근·시대 범위·번역/재배포 허용 조건·제3자 예외를 먼저 확인해야 한다. 접근 거부를 우회하지 않고, 권리 불명은 ‘미확인’으로 남긴다. 적법한 후보가 없으면 특정 권리자 허가 또는 다른 자료가 필요하다는 한계를 밝힌다. 임의로 무허가 번역하여 공백을 채우지 않는다.

## 역사에 근거한 세계관의 남은 검수

후보38개는 초안이다. 각 후보의 제도·사건 근거를 해당 원문 위치와 다시 대조하고, 원저의 주장과 현대 확인 사실과 독립 허구를 세 칸으로 나눠 검수해야 한다. 실제 사건의 연대·친족관계·전쟁·학살·식민 지배 등은 현대 신뢰 자료로 추가 확인해야 한다. 식민주의적 정당화와 민족·인종·종교적 위계를 사실 규칙으로 옮기지 않는다. 실제 피해나 강제 노동을 단순 보상 장치로 만들지 않는다.

현재 후보 수와 파일 저장이 모든 내용의 고증 완료를 뜻하지 않는다. 이름·지명·연대의 현대 확인 여부, 창작으로 바꾼 요소, 여전히 불확실한 점을 사용자에게 보여줄 수 있도록 편집해야 한다. 검수 전에는 서비스 공개용 확정 카드가 아니라 연구 후보로 유지한다.

## 서비스 적용에서 남은 일

애플리케이션·DB·기존 장르 템플릿은 수정하지 않았다. 커밋·푸시도 하지 않았다. 아래는 실행한 일이 아니라 후속 작업의 조건과 범위다.

1. 서비스의 실제 용도와 상업성, 공개 대상, 다운로드·재배포 방식에 맞는 권리 검토. 비영리 자료와 조건 불명 자료를 자동으로 상용 데이터에 넣지 않는다.
2. 원문 식별자·판본·출처URL·허용조건·범위·번역상태·검수상태·허구 구분을 담을 데이터 구조 설계. PG 전사판의 보정 표제는 원서 인쇄 표제와 구별한다.
3. 후보별 내용을 사용자용 카드로 편집하고 해당 카드의 근거·변경·현대사 공백을 표시. 통합 연구 초안 전체를 검수 없이 카드 데이터로 노출하지 않는다.
4. 기존 장르 보존 및 회귀검사, 카드 선택·출처보기·긴 한국어 텍스트 표시·잘못된 링크·누락 자료 처리 검증.
5. 구현 범위에 대한 지시와 저장소 작업 조건을 확인한 뒤 실제 반영. 외부 공개·배포·서비스 이용약관·권한 변경에는 해당 승인 요건을 별도로 적용한다.

최종 편집, 전수 전문 번역 교열과 역사감수, 현대사 공백 해소, 서비스 데이터 등록·UI·테스트·배포는 모두 현재 미완료다. 자료의 확보·번역·검수·권리 확인·구현을 각각 따로 보고한다.
