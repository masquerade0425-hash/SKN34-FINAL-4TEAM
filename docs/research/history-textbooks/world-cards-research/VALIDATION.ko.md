# 세계관 카드 검증 결과

## 파일·구조 검사

- 현재 브랜치 HEAD: feat/history-templates. 직접 HEAD만 읽었고 Git 명령·커밋·푸시는 실행하지 않았다.
- 8세계·177카드의 JSON을 엄격한 UTF-8로 읽었다. 기존 신화와 같은 세계/카드 필수 키 및 유형 구조다. 런타임의 장르 등록이나 화면 호환성 테스트를 했다는 뜻은 아니다.
- 세계·카드 UUIDv5 합계185개 중복0개. 기존 서비스 세계·카드ID와 충돌0개.
- 카드177개와 evidence177개 대응, JSON 카드본문177개와 Markdown 대응 통과.
- 스페인 제외7세계158카드의 모든 본문에 출전URL이 있다.226개 발췌의 원문 파일 해시·발췌 해시·행 범위를 재검증했다. 이 중30개는 명시된 행 범위의 일부분을 뽑은 발췌이며 나머지는 범위 전체다. 줄바꿈은 evidence의 정의를 따르며 한국의 바이트좌표도 일치한다.
- 스페인 실질17개 카드의18개 원문 문자범위·해시는 독립 검토에서 일치했다. 내용 검토와 권리 허가를 구별한다. 배지ND/문구SA 충돌로19카드는 권리 보류다.
- 기존941개 원문·번역·연구문서·서비스 템플릿 등의 크기와 해시를 작업 전후 대조해 변경0개다. 전체 저장소 모든 파일을 검사했다는 뜻은 아니다. 실제 .env는 열지 않았다.

## 내용 검사

7개국 각2개, 총14개 카드의 독립 표본 검수에서 중국 공자 카드의 행위 주체와 근거 범위를 수정했다. 수정 후 중국 발췌·출전·문서·해시를 재검증했다. 스페인17카드 검수에서 교육 개혁의 선후 표현을 수정했다. 자세한 대상은 [독립 검수 기록](INDEPENDENT-REVIEW.ko.md)을 따른다.

7개국158카드는141개 역사 내용과17개 범위·검수 카드로 구성된다. 전체 역사 내용의 독립 의미 검수·현대 역사 전문가 감수는 미완료다. 고전 이후 현대사 공백은 남아 있다. 스페인은17개 내용과2개 범위·권리 카드의 보류 초안이며 사용 가능한 완성본에 합산하지 않는다.
