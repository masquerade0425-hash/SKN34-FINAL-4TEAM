# 8개국 역사 출처 기반 세계관 연구 카드

기존 신화 세계관의 구조를 따라 국가별 세계1개와 인물·장소·조직·사건·규칙·검수 카드를 준비했다. 기존38개 허구 창작 후보와 다른 자료다. 실제 역사 문헌의 내용을 분류한 연구용 카드이며 가상 국가로 개명하지 않았다. 독일과 현대 통사 추가 확보는 보류했다.

**현재7개국 연구 초안158카드, 스페인 권리 보류19카드다.** 스페인을 사용 가능한 완성본에 합산하지 않는다. 나머지7개국도 현대 역사 전수 감수를 통과하거나 서비스 적용이 승인된 완성 데이터가 아니다.

## 스페인 권리 차단

교육부2016 교재 PDF2쪽 실제 배지는 BY NC ND이며, 아래 문구는 Atribución-NoComercial-CompartirIgual(BY-NC-SA)로 서로 다르다. 문구만 근거로 같은조건 개작 허가를 확정할 수 없다. [실제 페이지 이미지](noncommercial-spain/license-page2-review.png)와 [권리 보류 기록](noncommercial-spain/RIGHTS-HOLD.ko.md)을 남겼다. 기존 초안을 격리 보존하지만 권리자 확인 전 추가 개작·배포·서비스 적용을 중단한다. 비상업 격리만으로 ND/SA 충돌이 해결되는 것은 아니다. 이 차단은 교육부2016 교재에 관한 것이며 별도 Ayén 자료와 혼동하지 않는다. 권리자에게 외부 문의를 발송하지 않았다.

## 구성과 출처를 읽는 방법

각 .world.json은 기존 신화의 world 구조(genre,worldId,name,description,cards)를 따른다. 각 카드는 id,title,body,cardType을 가진다. UUIDv5로 만든 연구용 식별자이며 기존 세계·카드 식별자를 재사용하지 않는다. 문서와 JSON의 카드 본문은 같은 내용이다.

본문 출전줄에는 저자·서명·장/절/원문 위치와 원문URL을 넣었다. .evidence.json에는 실제 로컬 원문 파일·행 또는 PDF쪽/문자범위·원문 및 발췌 해시·불확실성을 담았다. 카드 본문만 복사하여 근거 파일을 버리지 않는다. 원문 존재 대조는 그 주장이 현대 역사학적으로 옳다는 보증이 아니다.

프랑스8장과 이탈리아11장에 걸친 내용이 포함되지만 모든 문단을 카드화하지 않았다. 미국·영국·일본·한국·중국도 여러 시대의 선택 주제다. 세계1개당 대표 카드 묶음이지 나라 전체 통사나 전체 번역을 대체하는 축약 정본이 아니다. 전체 번역 자료는 [상위 읽기 안내](../READING-INDEX.ko.md)를 따른다. 단, 스페인 교재의 예전 권리 안내는 새 권리 보류 기록으로 보완해야 한다.

## 시대·편향·미검증

미국은 현대까지 이어지는 확보 Yawp 본문을 사용했고 그 밖의 고전은 각각 영국1902년, 프랑스1871년, 이탈리아 주로1870년과1874년 평가, 일본1889년 헌법과1890년 의회 예고, 한국1904년, 중국1898년까지다. 이 범위를 현재의 국가 상태로 연장하지 않는다.

신화·건국 전승은 전승으로, 원저자의 역사 해석은 저자 주장으로 표시했다. 제국주의·인종·민족·종교 위계, 피해 축소, 의심되는 연대나 통계를 확정 사실로 만들지 않는다. 한국 I-A는 XI로 잘못 인쇄된 장에 PG가 붙인 식별자이며 원서의 인쇄 표제라고 부르지 않는다. 일본 헌법111조·거북선 철갑설·문자 기원설 등 의심 대목은 검수 대기로 분리했다.

미국 카드에는 사용한 장의 저자 크레딧·CC BY-SA4.0·변경 사항을 보존했다. 고전의 미국 공공영역 판단은 다른 관할권의 권리 보증이 아니다. 이미지·외부 인용 등 제3자 자료를 원저 본문의 허가로 묶어 서비스에 넣지 않는다.

## 완료와 미완료

- 완료: 국가별 연구 세계 구조, 원문 위치와의 대조, 카드·근거 대응, 출전줄, JSON/Markdown 정합성, 기존 파일 보존 검사.
- 독립 검수: 스페인17개 실질 카드와 해당 PDF쪽 검토; 다른7국은 각2개, 총14개 표본. 스페인 교육 개혁의 선후 표현과 중국 공자의 행위 주체·근거 범위를 바로잡았다. 전수 검수라고 부르지 않는다.
- 미완료: 독립 현대 역사감수·전수 문장 교열·고전 이후 현대사 보완·스페인 권리 충돌 해소·서비스 데이터 등록 및 화면·테스트·배포.
- 기존 장르·원문·번역·서비스 리소스와 DB는 변경하지 않았다. 연구 파일은 자동으로 서비스에 등록되지 않는다. 커밋·푸시하지 않았다.
