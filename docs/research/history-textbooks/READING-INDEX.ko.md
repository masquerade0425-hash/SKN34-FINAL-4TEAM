# 국가별 통합 초안 빠른 안내

이 목록은 실제 저장 파일로 이동하기 위한 안내다. 현대까지 이어지는 모든 나라의 최신 교과서 확보·전문 감수 완료를 뜻하지 않는다. 독일은 보류했다. 고전은 사료 번역이며 원저의 편견·오류를 현대 학계의 사실로 채택하지 않는다. 본문 저장, 부속자료 저장, 파일 구조 검사, 의미 검수, 역사적 사실 검증은 서로 다른 완료 범위다.

모든 원문과 기존 초안을 보존했다. 창작 후보는 총38개(미국20·프랑스4·스페인4·일본2·이탈리아2·중국2·영국2·한국2)이며 번역과 분리했다. 앱·DB에 등록하거나 커밋·푸시하지 않았다. 미국 외 주요 고전의 현대사 공백은 아직 해결되지 않았다.

## 공통 한계와 권리

한국어 초안 전수 전문 교열 및 현대 역사 전문가 감수는 미완료다. 개별 QA와 표본 검수는 전수 정확성 보증이 아니다. 미국 퍼블릭 도메인 표시는 다른 관할권에서의 권리 판단을 보증하지 않는다. 스페인과 현대 유럽 참고자료의 비영리·동일조건변경허락 및 제3자 예외를 상업용 앱이나 학습 자료에 그대로 적용 가능한 허가로 확대하지 않는다.

[상세 현황](README.md), [현대 자료 후보와 미해결 조건](MODERN-CANDIDATES.partial-ko.md), [현재 통합 파일 해시 목록](CURRENT-COLLECTION.manifest.json)을 함께 확인한다. 현대 유럽 Brooks2024 원문은 보조 참고 후보일 뿐 국가별 최신 통사의 대체본이 아니며 오류·별도 이미지 권리가 확인되어 무검수 번역 대상으로 채택하지 않았다.
