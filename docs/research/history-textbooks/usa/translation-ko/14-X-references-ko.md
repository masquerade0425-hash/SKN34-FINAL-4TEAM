# 제14장 재건: X. 참고자료

범위: X. Reference Material의 편집·기여자 정보와 추천문헌 25개, 주석 42개 전체. 원어 서지를 보존하고 비공식 한국어 제목·설명을 병기했다. 본문·그림 및 이미지 표의 셀 내용은 제외한다. 원저자·출판사의 승인이나 역사 전문가의 사실감수를 받지 않은 초안이다. 한국어 제목은 한국어판의 공식 서명이 아니며 설명은 해당 책을 별도로 읽고 쓴 서평이 아니다.
