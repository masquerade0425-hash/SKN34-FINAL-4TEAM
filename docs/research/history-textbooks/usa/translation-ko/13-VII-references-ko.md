# 제13장 남북전쟁: VII. 참고자료

범위: VII. Reference Material의 편집·기여자 정보와 추천문헌 25개, 주석 61개 전체. 원어 서지를 그대로 보존하고 한국어 제목·설명을 병기했다. 본문·그림 설명문은 제외한다. 비공식 한국어 번역 초안으로 원저자·출판사의 승인과 역사 전문가의 사실감수를 받지 않았다. 한국어 제목은 출판된 한국어판의 공식 서명이 아니며, 설명은 책을 별도로 읽고 작성한 서평이 아니다.
