# 제26장 흔들리는 미국: XI. 참고자료

범위: XI. Reference Material의 편집·기여·권장 인용, 추천문헌25개와 주석85개 전체. 원어서지를 보존하고 한국어 제목·설명을 병기했다. 제목은 비공식 번역이며 정식 한국어판 제목이나 미열람 문헌의 서평을 뜻하지 않는다. 비공식 한국어 번역 초안으로 원저자·출판사의 승인이나 역사 전문가의 사실감수를 받지 않았다.
