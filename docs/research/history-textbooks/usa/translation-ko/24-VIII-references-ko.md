# 제24장 풍요로운 사회: VIII. 참고자료

범위: VIII. Reference Material의 기여자·권장 인용·추천문헌25개·주석34개 전체. 원어서지를 그대로 보존하고 한국어 제목·내용 안내를 병기했다. 한국어 제목은 이해를 돕는 비공식 번역이며 정식 한국어판의 제목이나 미열람 문헌의 서평을 뜻하지 않는다. 비공식 한국어 번역 초안으로 원저자·출판사의 승인이나 역사 전문가의 사실감수를 받지 않았다.
