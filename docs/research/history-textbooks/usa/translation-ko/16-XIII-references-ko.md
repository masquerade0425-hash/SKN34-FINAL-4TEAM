# 제16장 제국의 지리: XIII. 참고자료

범위: XIII. Reference Material의 기여자 정보, 권장 인용, 추천문헌 29개, 주석 50개 전체. 원어 서지를 보존하고 비공식 한국어 제목·설명을 병기했다. 본문과 그림 설명문은 제외한다. 원저자·출판사의 승인이나 전문가의 사실감수를 받지 않은 초안이다. 한국어 제목은 출판된 번역판의 공식 서명이 아니며 설명은 해당 책을 별도로 읽고 쓴 서평이 아니다.
